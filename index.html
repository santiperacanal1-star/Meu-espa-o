AJUDA LOCAL E GRATUITA

Assistente pessoal

Um assistente simples que funciona no teu navegador, sem API paga. Usa os teus registos atuais para dar resumos e preparar eventos.

Este assistente usa regras locais, não um modelo de IA avançado. As mensagens não são enviadas para um serviço externo.
Olá! Posso resumir a tua semana, consultar os teus registos ou preparar um evento para o calendário. Experimenta: “marca treino amanhã às 18h”.

SINCRONIZAÇÃO

Conta e armazenamento na nuvem

Podes usar o site em modo local sem configurar nada. Para sincronizar os teus dados, cria um projeto Supabase e preenche as credenciais públicas abaixo. Nunca coloques uma chave service_role no navegador.

As credenciais ficam guardadas neste navegador. Para uma instalação pública com configuração centralizada, usa variáveis de ambiente no processo de compilação ou uma configuração segura do alojamento.
